## Planned outline

1. **Setting up the problem.** Writing equilibrium as $\mathbf{R}(\mathbf{u},\lambda)=\mathbf{0}$, with a load parameter $\lambda$.
2. **Newton's method and `fsolve`.** Solving at a fixed load, and why this fails near a limit point.
3. **Arc-length continuation.** Following the path through limit points by controlling a combination of load and displacement.
4. **Detecting instability.** Monitoring the determinant, or the smallest eigenvalue, of the tangent stiffness.
5. **A worked example.** The two-bar truss, with code that reproduces the curve in the [Computational Lab](/lab/von-mises-truss/).

A first sketch of the code the article will develop:

```matlab
% Equilibrium path of the two-bar truss (P in units of EA, L0 = 1)
alpha = deg2rad(15);  a = cos(alpha);  h = sin(alpha);
L = @(w) sqrt(a^2 + (h - w).^2);
P = @(w) 2*(1 - L(w)) .* (h - w) ./ L(w);
w = linspace(0, 2.2*h, 400);
plot(w/h, P(w)); xlabel('w/h'); ylabel('P/EA'); grid on
```
